# illust-turnaround

イラストを入れると、絵柄を崩さずに「首を振ると回り込んで見える」軽量なアバターを作るための実験リポジトリ。

考え方は次の3つ。

- 階層ごとに2Dメッシュを置き、各頂点を3Dの仮の形へ持ち上げて回す。縁の向こうへ回った部分は輪郭へ畳み込む
- 方向ごとの絵(全方位データ)を持ち、表面の区画ごとに「その面を正面寄りから見ていた絵」を重み付けして混ぜる
- 陰影(影・ハイライト・輪郭線)は模様と別の階層にし、視点側に残す

回転の動きは「頂点位置・不透明度・描画順」のキーに焼き込むので、Live2D(moc3)や Inochi2D と同じ種類のデータになり、実行時は軽い。

企画の全体像は Vault の「イラスト回り込みアバター構想」にある。

## 試作

### 1. リンゴ(`prototypes/apple`)

手続きで描いたイラスト風のリンゴ(セル影・輪郭線・ハイライト、縦縞と茶色の目印、ヘタ、葉)で、仕組みそのものを検証した。正解の3Dリンゴから、方向ごとの絵(リグの材料)と、任意角度の正解画像(採点用)の両方を作る。

```bash
pip install numpy scipy opencv-python-headless pillow
python3 prototypes/apple/apple25d.py prototypes/apple/results
```

結果(色の誤差は 0〜255 の平均、目印の誤差は px):

| 条件 | 輪郭の一致(IoU) | 色の誤差 | 目印の誤差 平均/最大 |
| --- | --- | --- | --- |
| 4方向・描いた角度 | 0.996 | 0.62 | 0.1 / 0.2 |
| 4方向・間の角度 | 0.994 | 1.03 | 0.1 / 0.3 |
| 4方向・15°ごとに焼き込み | 0.994 | 1.09 | 0.4 / 1.1 |
| 2方向(前後)・間の角度 | 0.963 | 2.71 | 0.2 / 0.3 |
| 4方向・上下にも傾ける | 0.990 | 5.00 | 2.7 / 12.3 |
| 6方向(上下を追加)・上下にも傾ける | 0.992 | 4.70 | 2.5 / 11.1 |

`results/` には、1周回転の GIF、間の角度での正解との比較、上下に傾けたときの比較、方向ごとの絵がある。

分かったこと:

- 絵に描き込まれた陰影を表面と一緒に回すと、影の境目やハイライトが二重になる。模様だけを回し、陰影を視点側に残すと正解とほぼ一致した
- 角度だけで絵を混ぜると、縁で透けたり穴が空いたりする。表面の区画ごとに重みを決めて正規化すると解消した
- 横の4方向だけだと、上から覗くと頂点に穴が空く。上下の絵を足す(六面図)と埋まった

残る課題: 上下に傾けたときの陰影(画面固定だと輪郭の形が合わない)。本物のイラスト(See-through の分解結果)と、3D復元した形での検証。
